# EBAC-ENG.QUAL
Atividades realizadas através do Postman.

Instruções seguidas:
 - Faça fork e clone do projeto do GitHub (https://github.com/EBAC-QE/hub-de-leitura-api), seguindo o passo a passo do README
 - Suba o servidor do Hub de Leitura em ambiente local
 - Identifique e mapeie os principais cenários da funcionalidade Catálogo de Livros, incluindo pelo menos dois cenários negativos
 - Crie uma collection no Postman, desenvolvendo requisições com os métodos GET, POST, PUT e DELETE
 - Valide o status das respostas e o cumprimento das regras de negócio, incluindo asserções em todas as requisições
 - Execute e revise os testes, garantindo o funcionamento correto dos cenários
 - Salve a collection final em formato .json e suba o arquivo em um novo repositório no GitHub
